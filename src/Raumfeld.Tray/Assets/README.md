# Raumfeld Desktop branding

The original black Raumfeld emblem is stacked above DESKTOP on white.
`raumfeld-original.jpg` is the unmodified reference supplied by the user:
https://i.pinimg.com/736x/73/59/7e/73597e97b5801b0946a0176e98b1fc9d.jpg

`raumfeld.svg` describes the source crop and centered native text. The matching
`raumfeld.png` is used by the panel. `raumfeld.ico` packages 16, 20, 24, 32, 48,
64, 128 and 256 pixel versions. The emblem itself is taken directly from the
source image rather than redrawn or regenerated.

Additional references:
- https://www.htgf.de/wp-content/uploads/2014/11/Raumfeld_Logo.jpg
- https://thomaskekeisen.de/resources/teufel_raumfeld/raumfeld-android.png

An image-generation draft was explored and discarded in favor of retaining
the original emblem exactly. The final lockup uses native composition.
